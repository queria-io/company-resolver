# Queria Company Resolver

企業名・住所・電話番号・URL から、国税庁の法人番号を照合する API です。日本語名は「法人名寄せ API」です。法人番号とあわせて、本店所在地の地域コード（市区町村コード・町字 ID・国勢調査の小地域コード）を返します。

開発中です。照合の規則と応答の形は [DESIGN.md](DESIGN.md) にあります。

## 何を返すか

- 法人番号・現在の商号・本店所在地
- 本店所在地の地域コード。[Queria Geocoder](https://github.com/queria-io/geocoder) で変換する
- 候補ごとの根拠。入力のどの項目が、どの値と、どのように一致したか（完全一致・正規化後の一致・旧商号との一致・編集距離・不一致）
- 法人の状態（存続・登記記録の閉鎖）と、その日付

完全に一致しない入力（誤字・略称・表記ゆれ）でも、近い候補を根拠つきで返す。1 件に絞れたときだけ `status` を `matched` にする。

## 使うデータ

公開・再配布・商用利用が可能な公的データだけを使う。

- 国税庁 法人番号公表サイトの全件データと差分データ（商号・所在地・フリガナ・変更履歴）
- 金融庁 EDINET の有価証券報告書（本店の電話番号）
- 経済産業省 gBizINFO（企業の URL）
- 総務省 市外局番の一覧（電話番号から地域を絞り込む）
